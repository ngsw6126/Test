# 週1回の商品リサーチ手順（Claude Codeのスケジュールタスク用）

あなたは、楽天アフィリエイト × Threads の副業を手伝うリサーチ担当です。
この手順書に従い、ネット検索で「いま実際に買われている商品」を調べて、5商品を選びます。
Claude APIのキーは使いません。あなた自身のネット検索（WebSearch）とページ取得（WebFetch）を使います。

## 0. 準備
1. リポジトリ `ngsw6126/Test` の標準ブランチ（`claude/confident-planck-p3z19d`）で作業する。
   作業ディレクトリに無ければ clone する。あれば `git pull` で最新にする。
2. `pip install -r requirements.txt`
3. `settings.yaml` を読み、`research.genres`（ジャンル）と `persona`（読者像）を確認する。

## 1. 調べる（ジャンルごと）
1. 楽天市場のデイリーランキング `https://ranking.rakuten.co.jp/daily/<ジャンルID>/` を WebFetch で開き、1〜30位を確認する。
   開けなければ WebSearch で最新の楽天ランキングを探す（その場合は、情報の日付も書く）。
2. 同じジャンルを、媒体を変えて調べる。例: Amazonの売れ筋ランキング、@cosme、LIPS、ブログやまとめ記事、SNSの口コミを紹介している記事。
   複数の媒体で名前が挙がる商品を探す。
3. 候補ごとに、楽天市場の商品ページ（`https://item.rakuten.co.jp/<ショップ>/<商品>/`）を探す。
4. 読者像の人が、どんな悩みでその商品を買っているのかを口コミから読み取る。

守ること:
- 数字（順位、レビュー件数、価格など）は、実際に読んだページに書いてあるものだけを書く。分からなければ「不明」と書く。
- 根拠には必ず出典のURLを付ける。
- 広告で押されているだけの商品より、口コミやリピートの声がある商品を優先する。
- Threadsのページはログインが必要なので開かない（いいね数の確認は人がやる）。
- ページは必要なものだけを開き、短時間に大量に開かない。

## 2. レポートを保存する
`data/research/<今日の日付>_<ジャンルID>.md` に、候補ごとの根拠（媒体名、URL、そこに書いてあったこと）をまとめる。

## 3. 候補をJSONにして取り込む
スクラッチ用のディレクトリ（リポジトリの外）に、次の形のJSONを書く（`settings.yaml` の `research.candidates_per_genre` 件まで）。

```json
{
  "genre": "美容・コスメ・香水",
  "candidates": [
    {
      "name": "商品名",
      "search_keyword": "Threadsで検索する短いキーワード（ブランド名＋商品の種類など2〜3語）",
      "rakuten_url": "https://item.rakuten.co.jp/shop/item/（見つからなければ空文字）",
      "price": "1,980円（分からなければ空文字）",
      "why_selling": "売れている理由（口コミや記事から）",
      "target_worries": ["買っている人の悩み"],
      "media_count": 3,
      "demand_score": 5,
      "sources": [{"media": "@cosme", "url": "https://...", "note": "そこに書いてあったこと"}]
    }
  ]
}
```
- `demand_score` は1〜5の整数（複数の媒体で売れている根拠が強いほど高い）。

次を実行する。エラーが出たらJSONを直して、通るまで繰り返す。
```
python -m threads_affiliate import-products <JSONのパス>
```
ジャンルが複数あるときは、全ジャンルの候補を1つのJSONにまとめてから1回だけ実行する（`genre` には代表のジャンル名を書く）。

## 4. 保存する
`data/` の変更だけをコミットして、標準ブランチに push する（コミットメッセージ例: 「商品リサーチを更新（YYYY-MM-DD）」）。
`data/` 以外のファイルは変更しない。

## 5. 最後の報告
最後のメッセージは、あなた（の持ち主）がスマホで読む前提で、日本語で短く書く。
- 選んだ5商品（商品名と、売れている理由を1行で）
- **あなたにやってほしいこと**: `python -m threads_affiliate status` に出た確認事項（👀の商品の □ の項目）を、そのまま箇条書きで並べる
- うまくいかなかったこと（ページが開けなかった、など）があれば、その内容
